# Mathmania v0.1.0.0

Mathmania is a small mathematical programming language that can display arbitrarily large `Natural` numbers, limited only by available memory.

## Example

```text
// This is a comment
show 122333444455555666666777777788888888999999999
```

Output:

```text
Natural => 122333444455555666666777777788888888999999999
```

## Reference

### Comments

Mathmania supports only single line comments written like `// ...`.

### Types

- `Natural` : Represents a natural number in the range `[1, ∞)`

### Keywords

- `show` : Displays a *value* of any *type* in a human-readable way
